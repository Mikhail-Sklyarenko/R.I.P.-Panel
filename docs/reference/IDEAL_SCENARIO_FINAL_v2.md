# Диспетчер + Agent + csgobot (много acc, пачки/конвейер)
## Финальный документ — версия 2

**Дата:** 2026-05-29  
**Версия:** 2.0  
**Основной бот в игре:** [csgobot](https://github.com/Priler/csgobot) (computer vision + YOLO)  
**Резервный бот:** simple (движение + anti-AFK)  
**Режим фарма:** «Бой насмерть» (официальный поиск)  
**Масштаб:** 16 рабочих ПК, 200+ acc, ротация пачками / конвейер  

---

# Часть 0. О чём этот документ

Описание **целевой системы** «под ключ»:

- **1 диспетчер** — центр управления, очереди, отчёты;
- **16 agents** — по одному на каждый рабочий ПК;
- **в agent встроен csgobot** — основной бот в DM (видит врагов, наводится, стреляет);
- **simple-бот** — запасной режим (слабый ПК, поломка AI, A/B тест);
- **200 acc** крутятся **конвейером** (~12–13 acc на каждый PC за неделю);
- **proxy/VPN на каждом PC** — отдельный IP для Steam/CS2;
- **looter** — автосбор дропа (на базе FSM `looter_core.js`).

# Часть 1. Главная идея

## 1.1 Аналогия

**16 станков**, **200 деталей**, **1 начальник** (диспетчер).

На каждом станке **робот-сварщик** (csgobot): **смотрит** на деталь в работе (экран CS2), **реагирует** (стрельба), а не только крутит деталь по таймеру.

Если робот сломался или станок слабый — включается **простой режим** (крутилка по расписанию).

## 1.2 Три слоя

| Слой | Кто | Задача |
|------|-----|--------|
| **Управление** | Диспетчер + вы (Telegram) | Кто когда фармит, куда дроп, прогресс 200/200 |
| **Исполнение** | Agent на каждом PC | Steam, CS2, смена acc, looter |
| **Игра в DM** | **csgobot (основной)** | Видит врагов, aim, shoot |
| **Запас** | simple-бот | Бег, anti-AFK без AI |

# Часть 3. csgobot внутри agent

## 3.1 Что делает csgobot (основной бот)

**Только пока acc в «Бой насмерть» на сервере:**

1. **Снимает** картинку с окна CS2 (grabbers из csgobot).
2. **YOLOv8** ищет игроков: CT/T, тело/голова (классы `c`, `ch`, `t`, `th`).
3. **Выбирает** цель (ближайший враг, приоритет голове).
4. **Двигает** мышь (FOV + Win32).
5. **Стреляет** (auto_shoot — **доработка**, в оригинале только aim).
6. Работает **в цикле**, пока agent не скажет «стоп» (level up / таймаут).

**Без чтения памяти игры, без инжекта** — только экран + мышь/клавиши.

## 3.2 Что csgobot НЕ делает (делает agent)

| Задача | Модуль agent |
|--------|----------------|
| Связь с диспетчером | Connector |
| Запуск Steam, 2FA, maFile | Launcher |
| Смена acc (200 ротация) | Account Switcher |
| Меню → DM → поиск | DM Runner |
| **csgobot** | **Combat Module** |
| Level up | Level Detector |
| Looter, trade | Looter Runner |
| Proxy для игры | Network (OS-level VPN) |

## 3.3 Структура agent (модули)

```
AGENT
├── connector/          → диспетчер
├── vault/              → ~12 maFiles локально на PC
├── launcher/           → Steam + CS2
├── dm_runner/          → Бой насмерть
├── combat/
│   ├── csgobot_ai/     → ОСНОВНОЙ (YOLO + aim + shoot)
│   └── simple/         → ЗАПАСНОЙ (WASD + anti-AFK)
├── level_detector/
├── looter/
└── proxy_check/        → IP перед стартом
```

## 3.4 Что нужно доработать в csgobot при встраивании

| Из репозитория | Доработка в agent |
|----------------|-------------------|
| Aim (мышь) | ✅ использовать |
| Detect (YOLO) | ✅ + рабочие веса `.pt` |
| auto_shoot | ❌ **добавить** (click при наведении) |
| CAPS LOCK вкл | ❌ убрать — старт от agent |
| 1 окно | ✅ 1 acc = 1 окно |
| 360×270 (FSM) | ⚠️ тест / upscale / дообучение |
| Зависимости | PyTorch, ultralytics, OpenCV |

# Часть 4. Гибрид: ai + simple

## 4.1 Зачем гибрид

- Не все 16 PC имеют **нормальную GPU**.
- **200 acc** на **AI везде** — лишний риск (поведение aimbot) и нагрузка.
- При **падении** YOLO / патче CS2 — **fallback** без остановки конвейера.

## 4.2 Режимы bot_mode

| Режим | Когда | Поведение в DM |
|-------|-------|----------------|
| **`ai`** (основной) | PC с GPU, модель OK | csgobot: видит → aim → shoot |
| **`simple`** (запасной) | Слабый PC, ошибка AI, ваш выбор | Бег, повороты, редкая стрельба |
| **`auto`** (рекомендуется) | По умолчанию | Пробует `ai`; при fail → `simple` + отчёт |

## 4.3 Как диспетчер назначает режим

**При регистрации PC:**

```yaml
PC-1:  gpu: true,  bot_default: ai
PC-3:  gpu: false, bot_default: simple
PC-7:  gpu: true,  bot_default: auto
```

**В команде «Старт»:**

```yaml
account: acc-103
pc: PC-7
bot_mode: ai        # или simple / auto
team: ct            # для csgobot — своя команда
trade_link: storage_3
```

**Рекомендация для 200 acc / 16 PC:**

- **10–12 PC** → `ai` или `auto`;
- **4–6 PC** → `simple` (конвейер не останавливается, разнообразие поведения).

## 4.4 Fallback ai → simple (автоматически)

Agent переключается на simple, если:

- GPU недоступна;
- модель `.pt` не найдена;
- inference < 5 FPS (слишком медленно);
- 3 раза подряд «нет кадра» / ошибка grabber;
- диспетчер прислал `bot_mode: simple`.

**Отчёт диспетчеру:** `combat_fallback: ai→simple, reason: gpu_missing`

# Часть 5. Требования к GPU и железу

## 5.1 Классы PC

| Класс | GPU | bot_mode | Ожидание |
|-------|-----|----------|----------|
| **A — AI** | NVIDIA 6+ GB VRAM | `ai` / `auto` | csgobot 30–60+ FPS inference |
| **B — Lite** | iGPU / слабая | `simple` | Без YOLO |
| **C — Auto** | Любая | `auto` | AI если тянет, иначе simple |

## 5.2 Минимум на 1 PC (1 acc в DM, csgobot ai)

| Component | AI (класс A) | Simple (класс B) |
|-----------|--------------|------------------|
| CPU | 4+ ядер | 2+ ядер |
| RAM | 16 GB | 8 GB |
| GPU | GTX 1660 / RTX 3050+ | не нужна |
| VRAM | 6 GB+ | — |
| Диск | SSD | SSD |
| OS | Windows 10/11 | Windows 10/11 |

## 5.3 16 PC — пример раскладки

| PC | Класс | acc в очереди | bot |
|----|-------|---------------|-----|
| 1–12 | A | ~12–13 each | ai / auto |
| 13–16 | B | ~12–13 each | simple |

**200 acc за неделю:** AI на ~150 acc, simple на ~50 — **баланс риска и железа**.

## 5.4 Нагрузка по времени

На **одном** PC **одновременно**:

- 1× CS2;
- 1× csgobot (только в DM, ~1 ч);
- **не** 12 нейросетей параллельно.

→ **1 GPU на PC достаточно** для конвейера.

## 5.5 Разрешение CS2 и YOLO

FSM-стиль: **360×270** (экономия).

| Вариант | Плюс | Минус |
|---------|------|-------|
| 360×270 + upscale перед YOLO | Мало RAM/GPU | Точность ниже |
| 1280×720 | Лучше detect | Тяжелее |
| Обучить модель на 360p | Оптимально | Нужен датасет |

**v2 рекомендация:** старт на **720p** на AI-классе; позже оптимизация под 360p.

# Часть 6. Много acc (200) — хранение и конвейер

## 6.1 Разделение acc по PC

**200 ÷ 16 ≈ 12–13 acc на PC.**

Формула: acc **N** → PC **((N−1) mod 16) + 1**

| PC | Acc (пример) |
|----|--------------|
| PC-1 | 1, 17, 33, 49, … 193 |
| PC-2 | 2, 18, 34, … 194 |
| … | … |
| PC-16 | 16, 32, 48, … 200 |

**На диске PC:** maFiles + пароли **только своих** acc (шифрование).

## 6.2 Конвейер (не ждать всю пачку)

```
PC-1: acc-1 [ai] → acc-17 [ai] → acc-33 [ai] → ...
PC-2: acc-2 [ai] → acc-18 [ai] → ...
...
```

- Закончил acc → пауза **3–8 мин** → следующий.
- **16 PC параллельно** — максимальная загрузка.

## 6.3 Пачки / волны (для отчётов)

- **Волна 1:** acc 1–16 стартовали;
- **Волна 2:** acc 17–32;
- … **Волна 13:** acc 193–200.

Telegram: «Волна 7/13 закрыта. Прогресс: 112/200.»

## 6.4 Время (200 acc, 16 PC)

| | |
|---|---|
| ~1–1,5 ч на acc (DM + csgobot + looter) | |
| ~13 acc на PC | |
| **~15–20 ч** полного прогона при 24/7 | |
| Запас до reset недели | **1–2 суток** фарма + буфер на сбои |

# Часть 7. Proxy и IP

- **Каждый PC** — **свой** exit IP для **Steam + CS2** (tunnel/VPN на весь ПК или только игру).
- **~12 acc / неделю / 1 IP** — компромисс (дешевле 200 IP).
- Agent **перед стартом** проверяет IP → отчёт диспетчеру.
- Связь **agent ↔ диспетчер** — обычный интернет (proxy для игры **не обязателен** для связи).

# Часть 8. Полный сценарий одного acc (v2 с csgobot)

## 8.1 Команда от диспетчера

```
START | PC-7 | acc-103 | bot_mode: ai | team: ct | trade: storage_3
```

## 8.2 Шаги agent

| # | Действие | Модуль | Отчёт |
|---|----------|--------|-------|
| 1 | Проверка proxy IP | proxy_check | `ip_ok` |
| 2 | Steam login + 2FA | launcher | `steam_ok` |
| 3 | CS2 launch (low settings) | launcher | `cs2_ok` |
| 4 | Главное меню | dm_runner | `in_menu` |
| 5 | Бой насмерть → поиск | dm_runner | `searching_dm` |
| 6 | В DM, загрузка карты | dm_runner | `in_dm` |
| 7 | **Старт csgobot** | **combat/csgobot_ai** | `combat_ai_started` |
| 8 | **Цикл:** grab → YOLO → aim → **shoot** | csgobot | каждые 5 мин `farming` |
| 9 | Level up | level_detector | `level_up` |
| 10 | **Стоп csgobot** | combat | `combat_stopped` |
| 11 | Disconnect / выход | dm_runner | `exited` |
| 12 | Looter → trade | looter | `loot_ok` |
| 13 | Close Steam | launcher | `done` |
| 14 | Пауза 3–8 мин | — | `idle` |
| 15 | Следующий acc из очереди PC-7 | connector | `start acc-119` |

## 8.3 Если csgobot упал на шаге 7–8

1. Agent: retry AI **1 раз**.
2. Не помогло → **`combat_fallback: simple`**.
3. Simple-бот до level up / таймаута.
4. Telegram: «acc-103: AI fallback, simple used».

# Часть 9. Диспетчер — память и правила

## 9.1 Таблицы

**PC:** id, online, gpu_class, bot_default, last_ip, last_ping  

**Account:** id, pc_id, farmed_week, status, last_drop, bot_used (ai/simple)  

**Queue per PC:** ordered list ~12 acc  

**Trade pool:** links + count per week  

**Combat log:** acc, bot_mode, enemies_detected, fallback (yes/no)

## 9.2 Правила retry

| Событие | Действие |
|---------|----------|
| DM search > 90s | retry ×2 |
| AI fail | fallback simple |
| In DM > 90 min, no level | stop, manual |
| Looter fail | retry ×1 |
| PC offline 15 min | pause queue, alert |
| Steam login fail ×2 | skip acc, next |

## 9.3 Trade pool

- **5–10** хранилок, ротация;
- **не** 200 acc → 1 link.

# Финальная фраза v2

**Диспетчер ведёт 200 аккаунтов и 16 конвейеров; agent на каждом ПК запускает Steam, заходит в «Бой насмерть» и включает встроенный csgobot — бот с «глазами», который стреляет по врагам; если GPU или модель не справляются, agent сам переключается на простой бот; после уровня looter забирает дроп, и на том же ПК через несколько минут стартует следующий acc из очереди — вы управляете всем одним центром с телефона.**
