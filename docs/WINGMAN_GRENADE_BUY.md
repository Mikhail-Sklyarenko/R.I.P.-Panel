# Wingman: гранаты после основного закупа

Дополнение к `wingman-inferno-fix-10`. Распаковать архив `wingman-grenade-buy.zip` в корень `R.I.P.-Panel` с заменой файлов при остановленном фарме. Виртуальное окружение и настройки не меняются.

Сначала выполняется существующий основной закуп: броня, доступное основное оружие, набор обезвреживания для CT. Только остаток бюджета используется для гранат в порядке: дымовая, осколочная, световая, Молотов для T / зажигательная для CT. Если очередная граната не по карману, рассматривается следующая. Покупается не более одной гранаты каждого типа; сохранённые гранаты учитываются, огневые гранаты занимают общий тип, общий лимит — четыре. Две сохранённые световые в одной записи GSI считаются двумя гранатами.

Команды выполняются последовательно с подтверждением инвентаря и уменьшения денег. При неподтверждённой основной покупке закупка гранат не начинается. В журнал добавлена строка `buy_grenades remaining_after_core=... items=...`.

Раскидка не добавлена. Навигация, стрельба и режим Deathmatch не изменены. Живой прогон на Windows этой версии не выполнялся.

Каталог зажигательной CT использует цену 500: [официальные изменения Valve от 23.05.2024](https://store.steampowered.com/news/posts/?appids=730&enddate=1719429748&feed=steam_community_announcements). Подтверждение каждой покупки остаётся обязательным; несовпадение фактической стоимости останавливает транзакцию.
