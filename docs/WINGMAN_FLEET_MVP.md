# Напарники Inferno — продуктовый флот (MVP)

Четыре ПК, четыре заранее авторизованных аккаунта Steam, две постоянные пары.
Координатор работает на одном из игровых ПК. Каждая машина запускает агента.
Игровой runtime Inferno включается только после доказательства общего матча.

## Состав

```
Слот 1 — лидер пары 1
Слот 2 — ведомый пары 1
Слот 3 — лидер пары 2
Слот 4 — ведомый пары 2
```

Порядок не сдвигается. Ведомый никогда не становится лидером автоматически.

Пароли и Steam Guard панель флота не хранит. Первый вход — вручную, с сохранением авторизации.

## Установка на каждом ПК

1. Та же сборка Farm Panel (одинаковая версия и ресурсы Inferno).
2. CS2 1280×720, русский HUD, OBS Virtual Camera, один раз перезапустить CS2 после записи GSI.
3. Вкладка **Wingman**:
   - на главном ПК роль `coordinator`, порт `8790`, общий токен ≥ 24 символов;
   - на остальных роль `agent`, URL `http://<IP-координатора>:8790`;
   - `wingman_fleet_agent_id` = id слота этого ПК;
   - ожидаемый SteamID64;
   - заполнить все четыре слота (имя в CS2 должно быть уникальным — по нему доказывается общий матч).
4. Открыть входящий TCP 8790 на координаторе.
5. **Координатор** → **Агент** → **Старт цикла**.

Headless:

```
FarmPanel.exe --fleet-coordinator
FarmPanel.exe --fleet-agent
```

На ПК координатора запускают оба флага или панель.

## Что делает система

1. Heartbeat 2 раза в секунду. Нет связи 3 с — ввод отпускается.
2. Preflight блокирует пару, если SteamID, GSI, камера, 1280×720 или профиль Inferno не готовы.
3. Дружба один раз, затем лобби, приглашение, проверка состава.
4. Синхронный поиск. Если пары попали в разные матчи — выход, новое лобби, повтор с лимитом волн.
5. Игровой бот стартует только при `SAME_MATCH_CONFIRMED`.
6. После матча возврат в меню и следующий цикл до Стоп / cooldown / исчерпания бюджета.

## Диагностика

- `data/fleet/coordinator.db` — команды и переходы.
- `data/fleet/journal-<agent>.db` — ровно одно выполнение каждой команды.
- `data/logs/fleet/<agent>/` — скриншоты отказов.
- Панель показывает конкретную причину, например: `ПК-2: приглашение получено, принятие не подтверждено`.

## Приёмка

Не считать MVP готовым, пока не пройдут:

- 10 последовательных общих матчей Inferno;
- отключение сети / CS2 / агента / координатора;
- чужой SteamID;
- разные матчи;
- отсутствие бесконечных повторов и залипшего ввода.

Калибровка кликов: `resources/ui_nav/wingman_fleet.yaml`. Неизвестный экран запрещает действие.
