# Navigation Studio

Локальный редактор маршрутов и центр проверки визуальной навигации.

## Запуск на Windows

Распакуйте обновление в корень R.I.P.-Panel с заменой файлов. Запустите tools/navigation/NavigationStudio.bat: откроется браузер. Используется существующая Python-среда csgobot. В панели, запущенной из обновлённых исходников, также есть кнопка Navigation Studio. Старый собранный EXE не получает новую кнопку без пересборки; BAT работает отдельно.

## Маршруты

1. Выберите карту. Для Dust2 уже есть исходный Mid и его ограниченная маска проходимости.
2. Выберите маршрут или создайте новый. Клики добавляют цели, перетаскивание перемещает их. Колесо масштабирует карту, правая кнопка перемещает вид.
3. Для нового участка нарисуйте полигон прохода. Enter завершает полигон, Esc отменяет. Черновик не расширяет рабочую маску. Подтверждайте участок только после проверки в игре, укажите основание в заметке. Препятствия всегда исключаются из проходимой области.
4. Проверьте маршрут. Учитываются зазор от стен и все переходы, включая возврат от последней цели к первой: маршруты циклические. Зазор задаётся в пикселях карты.
5. Соберите маршрут. Создаётся отдельная неизменяемая сборка с контрольными суммами. Изменения проекта требуют новой сборки.
6. На Windows нажмите запуск CS2-сеанса, вернитесь в игру и нажмите F8 для включения движения. Повторный F8 отключает движение. CapsLock также работает при удержании. Начинайте внутри подтверждённой области. Кнопка остановки Studio передаёт сигнал освобождения управления.

## Запись и импорт

Запись ручного прохода не посылает клавиши или мышь. Она сохраняет видео 10 fps и измеренные позиции; требует Windows, активного окна CS2 и захвата 1280×720. Завершите сеанс, импортируйте запись и выберите отдельный непрерывный сегмент для создания маршрута. При потере позиции, большом временном разрыве или скачке координат сегмент разрывается. Импорт не доказывает проходимость и не обучает атлас автоматически.

Можно импортировать JSON/JSONL из файла. Проверка видео принимает путь к локальному видео; сейчас поддерживает Dust2. Низкая доля найденных позиций означает, что нужно расширять или исправлять визуальный профиль, а не просто добавлять цели.

## Данные и ограничения

Проекты, сборки и сеансы сохраняются в data/nav_studio (либо в FARM_PANEL_DATA_DIR/nav_studio). После перезапуска Studio записи остаются на диске; их можно импортировать из файла. Список сеансов в интерфейсе относится к текущему запуску.

Готовность маршрута означает геометрическую связность на маске, а не успешное прохождение в CS2. Новые функции проверены локальными тестами и через интерфейс; Windows-захват и реальное прохождение этого релиза ещё не проверены. Встроенный визуальный профиль покрывает центральный Mid Dust2, не всю карту. Редактор других карт не создаёт для них визуальную локализацию. Этажи, двери и прыжки не моделируются.

Сглаженный контроллер камеры и освобождение управления при потере свежей позиции сохранены. Маршрут Studio запускается отдельным nav_live-сеансом; он не подменяет автоматически маршрут основного боевого цикла панели.
