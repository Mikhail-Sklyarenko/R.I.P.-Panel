# Vertigo: навигация с раздельными этажами

Vertigo подключён к той же панели и тому же процессу, что Dust2, Mirage и Inferno. `CSGOBOT_NAV_PACK=auto` выбирает карту по названию HUD либо по геометрии радара. Навигация работает с существующим владением камерой: при противнике управление получает автострельба, при отсутствии противника — навигация.

## Реализовано

- Отдельные радары, HUD-атласы и маски проходимости верхнего и нижнего этажей. Нижний этаж — внутренний ресурс `de_vertigo_lower`, а не пятая карта в панели.
- Координаты содержат измеренный `layer_id`. После смерти, перемещения или смены этажа позиция подтверждается заново; прежний маршрут, препятствия и история восстановления не переносятся на другой этаж.
- Свободный выбор целей внутри текущего этажа. При продолжительном перемещении бот выбирает доступный переход между этажами: лестницы B либо рампу A. Выбор не зависит от заранее заданного спавна.
- Двусторонние переходы представлены проверяемыми путями, а не объединением этажей. Шахта с вертикальной лестницей исключена из обычного выбора путей: подъём по ней не реализован. Доступ к обоим этажам обеспечивают пешие переходы.
- Фоновый поиск атласа включается при потере измерения; успешный поиск не дублируется в двух потоках. Более старый результат не заменяет свежую визуальную опору.
- Сохранены плавное управление камерой, движение WASD во время поворота, выход с границы проходимости и восстановление после застревания. Shift не добавлялся; параметры автострельбы не менялись.
- Исходные RGBA-радары сначала компонуются на чёрный фон. Скрытые RGB-пиксели при нулевой прозрачности не становятся стенами или проходимой поверхностью.

## Данные и воспроизводимость

Исходная запись: `2026-09-13 16-56-44.mp4`, 1280×720, 137,7 секунды. В атласах 66 опорных кадров с чётных секунд: 39 верхнего этажа и 27 нижнего. Часть привязок получена строгим контурным сопоставлением, часть проверена визуальным наложением контуров; происхождение отмечено у каждой привязки.

Источники изображений: [верхний радар](https://raw.githubusercontent.com/MurkyYT/cs2-map-icons/main/images/radars/de_vertigo_radar_psd.png) и [нижний радар](https://raw.githubusercontent.com/MurkyYT/cs2-map-icons/main/images/radars/de_vertigo_lower_radar_psd.png). Оригиналы, контрольные суммы и обработанные изображения находятся в `resources/nav/maps/`.

`scripts/rebuild_vertigo_profile.py --video <исходная запись> --out <новая папка>` восстанавливает оба этажа без изменения установленного профиля. Проверено побайтное совпадение 75 файлов. Проверки включают разделение этажей, связность переходов, случайные стартовые позиции, очистку маршрута при смене этажа, обработку прозрачности и совместимость прежних карт.

Итоговые результаты находятся в `resources/nav/profiles/de_vertigo/validation.json`. Покрытие распознаванием по записи не равно точности координат, успешному движению или независимой живой проверке. Запись использована для калибровки; нечётные проверочные кадры находятся рядом с калибровочными во времени. Программа не управляла игрой во время replay. `live_validated` и `full_map_ready` остаются `false` до живой проверки. Спавны на ящиках, лестницы, прыжки и временные препятствия не подтверждены таким прогоном.




Итог: 98 автоматических проверок пройдены; на полном видеопрогоне принято 1098 из 1370 кадров (80.15%). Самый длинный провал локализации при видимом значке — 2.5 с. Это показатели распознавания по записи, не подтверждение непрерывного движения в игре.

## Установка и запуск

1. Закройте панель и процесс бота.
2. Распакуйте `farm-panel-vertigo-v9.zip` в существующий корень `R.I.P.-Panel` с заменой файлов.
3. Включите виртуальную камеру OBS и запускайте `FarmPanel.bat`.

Версия в логе — `visual-nav-multimap-9`; после определения карты — `vertigo_visual`; после измерения позиции — `layer=upper` либо `layer=lower`. Отдельный экземпляр панели или отдельный запуск навигации не нужен. Старый собранный EXE не пересобирался: пакет обновляет исходную панель.

Для ручного запуска из CMD в тренировке:

```bat
cd /d C:\Users\FermK\Downloads\R.I.P.-Panel
set CSGOBOT_NAV=1
set CSGOBOT_NAV_READ_ONLY=0
set CSGOBOT_NAV_MODE=expanded_roam
set CSGOBOT_NAV_PACK=auto
set CSGOBOT_TARGET_MODE=ffa
set CSGOBOT_AUTO_ACTIVATE=0
cd vendor\csgobot
venv\Scripts\python.exe -u run.py
```

CapsLock активирует бота, Ctrl+Q завершает процесс.
