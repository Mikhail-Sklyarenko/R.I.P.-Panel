# Inferno: навигация и автоматический выбор карты

Обновление `visual-nav-multimap-6` добавляет Inferno в общий запуск
`FarmPanel.bat`. Поддерживаются Dust2, Mirage и Inferno. Отдельный процесс
навигации не нужен: worker выполняет навигацию и стрельбу совместно.
Настройки короткой очереди и обратной связи мыши из v5 сохранены.

## Что реализовано

- Определение Inferno по геометрии миникарты без открытия TAB; подтверждение
  требует трёх последовательных однозначных совпадений. Добавлен разбор
  названия Inferno в OCR и поддержка соответствующих HUD-шаблонов в загрузчике.
  Отдельного нового шаблона экрана принятия матча в записи нет.
- Автоматическая смена профилей трёх карт с удалением старой позиции,
  маршрута, временных препятствий и результатов фонового распознавания.
- Свободный выбор целей на связной сети пола: T, Banana, B, CT, Mid, A,
  апартаменты. Маршрут пересчитывается по измеренной позиции, а не
  воспроизводит пробежку из видео. После нового спавна требуется новое
  подтверждённое измерение позиции.
- 68 калиброванных HUD-изображений: 21 прямое геометрическое совпадение и
  47 сопоставлений контуров, проверенных визуально. Координаты привязаны
  непосредственно к радару, без накопления перемещения между кадрами.
- Из геометрических признаков Inferno исключено внутреннее кольцо радара.
  В режиме полупрозрачного радара фон сцены допускается только при
  однозначном совпадении и распределённой по площади поддержке контуров.
  Порог приёма других карт не изменён.
- При известном масштабе Inferno сначала проверяется быстрый поиск по всей
  карте, затем сопровождение изображения. Во время боя используется только
  лёгкое сопровождение, без итеративного ECC в основном потоке.
- Сетка Inferno — 2 пикселя; отступ от стен — 4 пикселя схемы. Прежняя сетка
  и запас перекрывали узкий проход апартаментов. Схема не расширяется через
  стены для искусственного повышения связности.

## Проверки и их границы

В выборке из 39 кадров, не использованных как изображения атласа,
уверенное сопоставление получено на 32. Эти кадры взяты из той же записи и
близки по времени к калибровочным: это проверка покрытия записи, а не
независимая оценка точности на другой игре.

В 40 сопоставлениях Inferno с Dust2/Mirage и наоборот не было результатов
с уверенностью >= 0,70. Это ограниченный проверочный набор, не гарантия
отсутствия ошибок при любых настройках HUD.

Тесты проверяют соединение основных зон и узкой комнаты с остальной картой,
планирование из 30 распределённых точек, отсутствие пересечения запрещённых
ячеек, переключения трёх карт и отбрасывание неоднозначной геометрии.
На участке 60–90 секунд после изменения порядка обработки получены
238 валидных измерений из 300 вместо 212. Медианное время вызова обработчика
в этой среде снизилось со 189 до 41 мс. Это сравнение по видео на текущем
компьютере без YOLO, а не обещание FPS на Windows.
В финальном прогоне всей записи приняты 1275 из 1580 измерений
(80.7%). Пропуски локализации остаются. Итог: 155 тестов пройдены.
Метрики и точные хэши проверенного кода и профиля находятся в
`resources/nav/profiles/de_inferno/validation.json`.

Профиль описывает двумерную проекцию пола. Разные уровни, односторонние
спрыгивания, двери, столкновения игрового движка и все возможные случайные
спавны не подтверждены живым игровым тестом. Поэтому `live_validated` и
`full_map_ready` остаются false. Непрерывный бег без остановок на всей карте
пока не гарантируется; при длительной потере позиции worker отпускает движение.

## Установка

1. Закрыть панель и процесс бота.
2. Распаковать обновление в существующий корень `R.I.P.-Panel` с заменой файлов.
3. Включить виртуальную камеру OBS с изображением игры 1280×720.
4. Запустить `FarmPanel.bat`. В логе должна быть версия `visual-nav-multimap-6`,
   затем после распознавания Inferno — профиль `inferno_visual`.

Выбор карты остаётся автоматическим. Старый собранный EXE этим архивом не
пересобирается; используйте запуск исходников через FarmPanel.bat.

## Воспроизводимость

`resources/nav/maps/de_inferno/` содержит радар, его метаданные и исключённые
области. `resources/nav/profiles/de_inferno/` содержит атлас и маску пола.
Хэши исходного видео и радара зафиксированы в JSON.

Пересборка в новый каталог без изменения текущего профиля:

```text
python scripts/rebuild_inferno_profile.py --video VIDEO.mp4 --out NEW_DIRECTORY
```

Повторный прогон без отправки клавиш или мыши в игру:

```text
python scripts/nav_replay_check.py --map de_inferno --video VIDEO.mp4 --seconds 158 --async-perception --output data/inferno_replay.json
```

Радар и overview взяты из [cs2-map-icons](https://github.com/MurkyYT/cs2-map-icons),
предоставляющего извлечённые ресурсы CS2. Точная версия изображения закреплена
SHA-256, так что обновление внешнего репозитория не меняет готовый профиль.
