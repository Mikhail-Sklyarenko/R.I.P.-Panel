# Cache: автоматическая навигация в общей панели

Cache подключён к существующему процессу FarmPanel.bat вместе с Dust2, Mirage, Inferno и Vertigo. `CSGOBOT_NAV_PACK=auto` выбирает профиль по подтверждённому названию карты либо геометрии миникарты. После смены карты прежние координаты, маршрут и накопленные препятствия сбрасываются. При противнике камера остаётся у существующего модуля автострельбы.

## Что входит

- Радар Cache с корректной обработкой прозрачности, 82 опорных изображения HUD и маска наземной проходимости. Привязки получены независимым поиском по всей карте, без накопления смещения от предыдущей позиции.
- Свободный выбор целей по связной наземной сети обеих баз, A, B, центра и главных проходов. Маршрут не привязан к начальному спавну или последовательности в видео.
- Отдельная разметка реальных лестниц, порогов, ящиков и контейнеров. Цветные контуры зон установки и баз не разрывают проходы. Скрытые RGB-пиксели исходного PNG не превращаются в поверхность за пределами карты.
- Быстрый поиск текущей позиции по всему радару при известном масштабе HUD. Успешное измерение обновляет визуальную опору; фоновый поиск нужен только при потере измерения. Старый результат фоновой обработки не заменяет более свежую опору.
- Существующее управление камерой, непрерывное удержание WASD при допустимом пути, обход препятствий и восстановление после застревания. При потере достоверной свежей позиции ввод приостанавливается.

## Переходы и границы

Дверь «Скрип» исключена как прямое соединение A: маршрут использует главный проход. Верхушки ящиков, подъём по вертикальной лестнице, подсадки и пролезание через вентиляцию не назначаются обычными целями. Наземная сеть обеспечивает обходы; автоматическое прохождение каждого специального перехода и выход с произвольной возвышенности этим обновлением не подтверждаются.

Масштаб исходного HUD — 0.355; это подсказка масштаба, а не предположение о позиции. При несовпадении геометрии остаётся поиск атласа. Другая редакция Cache или существенно другой HUD требуют отдельной проверки соответствия.

## Воспроизводимость

Запись: `2026-09-13 16-59-35.mp4`, 1280×720, 194.48 секунды. Атлас использует чётные секунды. Нечётные кадры тестов не входят в атлас, но соседствуют с ними и не являются независимым набором точных координат.

Источник радара: [MurkyYT/cs2-map-icons — de_cache_radar_psd.png](https://raw.githubusercontent.com/MurkyYT/cs2-map-icons/main/images/radars/de_cache_radar_psd.png). Хеши записи и радара сохранены в профиле; профиль входит в идентификатор запуска `visual-nav-multimap-10`.

Повторное построение из исходной записи, из корня проекта:

```cmd
vendor\csgobot\venv\Scripts\python.exe scripts\rebuild_cache_profile.py --video "C:\path\2026-09-13 16-59-35.mp4" --out "C:\path\cache-rebuilt"
```

Каталог результата должен быть новым. Скрипт проверяет исходные данные и воспроизводит маску, опорные изображения и манифесты.

## Установка и запуск

Закрыть панель и процесс бота. Распаковать обновление в существующий корень R.I.P.-Panel с заменой файлов. Включить виртуальную камеру OBS и запустить FarmPanel.bat. Выбор карты — auto. Отдельный запускатель для Cache не требуется. Обновление содержит исходники; старый собранный EXE не пересобирается.

Тест с ботами через CMD:

```cmd
cd /d C:\Users\FermK\Downloads\R.I.P.-Panel
set CSGOBOT_NAV=1
set CSGOBOT_NAV_READ_ONLY=0
set CSGOBOT_NAV_MODE=expanded_roam
set CSGOBOT_NAV_PACK=auto
set CSGOBOT_TARGET_MODE=ffa
set CSGOBOT_AUTO_ACTIVATE=0
cd vendor\csgobot
venv\Scripts\python.exe -u run.py
```

CapsLock активирует бота, Ctrl+Q завершает работу. В логе должны появиться версия движка, подтверждённая `de_cache` и измеренная позиция. Если включилась другая карта, продолжать движение по её профилю нельзя: сохраните лог для диагностики.

## Проверки

Результаты воспроизведения записаны в `resources/nav/profiles/de_cache/validation.json`. Replay проверяет распознавание и свежесть координат, а не реальное прохождение маршрутов в Windows. Поэтому `live_validated` и `full_map_ready` остаются false до самостоятельного игрового прогона. Эти метки не отключают установленную навигацию.

Итог: 74 автоматические проверки пройдены. Replay: 1694/1940 кадров (87.32%); свежих к завершению обработки — 1649. Самый длинный провал локализации при видимом значке — 2.9 с. Эти цифры не доказывают безостановочное движение в игре.
