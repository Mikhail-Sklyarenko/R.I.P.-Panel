# Плавность движения: visual-nav-multimap-3

Обновление используется общим worker панели и отдельным scripts/nav_live.py.
Аим и навигация сохраняют общее владение камерой; распознавание Dust2/Mirage
и переключение профилей остаются автоматическими.

## Что изменено

- Поиск совпадения со всем атласом выполняется отдельным потоком с очередью
  только последнего кадра. Он больше не задерживает каждый такт управления.
- Текущий кадр миникарты сопоставляется с фиксированной привязкой. Вырезка
  приводится к единой системе координат: колебания оценки радиуса на пиксель
  больше не сбрасывают сопровождение из-за различия размеров изображения.
- При коротком пропуске можно использовать только настоящее измерение
  в пределах исходных 250 мс. Его время не обновляется. После потери иконки,
  неоднозначного совпадения или смены карты предыдущие привязки отбрасываются.
  Результат незавершённого поиска старой карты не попадает в новую карту.
- Начало движения допускается при ошибке направления до 25°, продолжение —
  до 40°, если перед персонажем остаётся проверенный свободный отрезок.
  Это убирает переключения W на небольших колебаниях около одного порога.
  Shift не применяется. Большой поворот, стена, потеря позиции или фокуса
  по-прежнему останавливают перемещение.
- Временная область обхода не может держать измеренную позицию внутри себя
  до истечения таймера: она сужается около занятой точки. Статическая маска
  стен не расширяется. Ограничение числа неудачных попыток сохраняется.

## Проверка

Тесты покрывают смену карты во время незавершённого поиска, потерю иконки,
старые кадры, неоднозначность, колебания размера вырезки, сроки ввода,
пороги начала/остановки движения и временные препятствия.

Для воспроизведения продуктового режима без отправки ввода в игру:

```text
python scripts/nav_replay_check.py --map de_mirage --video VIDEO.mp4 --start 35 --seconds 12 --async-perception --output data/nav_motion_replay.json
```

Без --async-perception инструмент сохраняет синхронный режим сравнения
локализации по атласу. В отчёте явно указан perception_mode.

На фрагменте 35–47 секунд записи 2026-09-13 18-15-33.mp4 отдельное сравнение
на Mac дало медиану обработки 112 мс для синхронного режима и 27 мс для нового.
Это время только восприятия, без YOLO и управления игрой. После первых двух
секунд новый режим принял 95 из 100 кадров, синхронный — 100 из 100.
Таким образом, ускорение не доказывает отсутствие пропусков локализации.
Запись не проверяет реакцию игры на новые команды. Живой прогон на Windows
и отсутствие застреваний на всех спавнах этой проверкой не подтверждены.

## Установка

Закрыть панель и worker. Распаковать обновление с заменой файлов в существующий
корень R.I.P.-Panel, рядом с FarmPanel.bat. Обычный запуск — FarmPanel.bat.
В логах версия должна быть visual-nav-multimap-3. Виртуальная камера OBS должна
передавать кадры игры 1280×720. Старый собранный EXE не обновляется этим архивом.
