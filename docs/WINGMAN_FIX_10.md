# Wingman Inferno — fix 10

Исправления по записи `2026-09-23 16-52-09.mp4` и журналу этого прогона.

## Подтверждённые причины

- Примерно 00:35–01:40: игрок уже приземлился на нижней площадке A после апартаментов, но оставалась активной узкая маска выхода из апартаментов. Журнал повторял `pose_outside_verified_ground`. Теперь выход в записанную зону приземления подтверждается двумя разными измерениями положения и возвращает основную маску. Это разрешено только после прохождения лестницы и вне верхнего коридора; произвольные наложения этажей переходом не считаются.
- Примерно 04:26–05:37: `no_player_icon` ещё ДО установки. Порог яркости выделял только кусочек фиолетового маркера, хотя белый указатель направления оставался виден. Исправлена сегментация тёмного насыщенного фиолетового тела. Направление берётся из белого указателя, а не из самого дальнего цветного пикселя.
- После установки, примерно 02:24, 06:47 и 07:32: при первых шагах значок C4 смещается относительно центра радара и смешивается с указателем игрока. Удаляется из расчёта направления весь распознанный дисплей C4 рядом с игроком, включая край сглаживания. Смещённая бомба не используется как координата игрока. Полностью скрытый указатель по-прежнему не даёт разрешения на движение.

После установки выбран отход с перемещением между доступными позициями вокруг A. Существующий планировщик guard продолжает выбирать следующую позицию после достижения текущей. Намеренное бессрочное стояние/приседание не добавлено. Основные исправления восстанавливают входные измерения для этого поведения.

## Проверки

- 274 проверки Wingman, навигации и Inferno; 57 проверок боевой логики.
- Проверки на новых кадрах охватывают чтение направления, реальные координаты, смещённый значок C4, выбор своего маркера вместо соседнего союзника, отказ при скрытом указателе, подтверждение приземления и фактическую выдачу клавиши движения после установки.
- Повторно просмотрен старый кадр `regression_v6/218.png`: у фиолетового игрока виден белый указатель вниз. Старое ожидание обязательного отказа было ошибочным. Теперь проверяется правильное направление и центр своего игрока; отдельный отрицательный тест удаляет именно этот указатель, сохраняя соседнего союзника.
- На восьми выбранных проблемных отрезках по 30 кадров значок читается в 240/240 против 79/240 у fix 9 на тех же кадрах. Текущая геометрическая локализация выдаёт положение в 205/240; на трёх отрезках после установки — 29/30 на каждом (первый кадр подтверждения). В апартаментах остаются краткие отказы геометрического сопоставления; 100% локализация не заявляется.
- Тест HTTP listener исключён из локального прогона из-за ограничений окружения. Боевой код в этом исправлении не изменялся. Изменения цветных маркеров включены только в competitive/Wingman ветке.

Это проверки записанных изображений и изолированного контроллера, не живой прогон новой версии в CS2. Успешное автоматическое обезвреживание этим прогоном не подтверждено.

## Установка

1. Остановить рабочий процесс фарма и закрыть панель.
2. Распаковать `wingman-inferno-fix-10.zip` в корень установленной `R.I.P.-Panel` с заменой файлов. В корне должны находиться `vendor`, `resources`, `modules`, а не ещё одна вложенная папка обновления.
3. Запустить прежним способом. В журнале должна появиться строка `wingman_fix_10: c4_offset_mask=on purple_body=on measured_landing=on defuse_look=on`.

Обновление накопительное поверх предыдущих Wingman-исправлений. В архиве нет виртуальных окружений, учётных данных или локального GSI-токена. Переустановка Python и зависимостей не требуется.
