# Combat v22

Точечное обновление наведения поверх текущих исходников проекта.

- Предыдущая точка EMA переносится в систему координат нового кадра по реально отправленным командам мыши. Без этого собственный поворот камеры оставлял запаздывающий след.
- Удерживаемая точка также переносится; скорость цели при включённом coast исключает собственное вращение камеры.
- Дальняя скорость: предел 32 вместо 20 единиц за тик; ближний предел 8 сохранён, переход между ними плавный. Переменная CSGOBOT_AIM_MOUSE_STEP_MAX по-прежнему имеет приоритет.
- Выстрел проверяется по измеренной точке цели с компенсацией уже отправленного движения, а не по сглаженной точке. Кадры старше 250 мс не разрешают новый выстрел.
- При пропуске детекции боевой режим сохраняется не более 100 мс. Мышь наведения очищается, огонь отпускается сразу; повторное появление не сбрасывает EMA. Длительная потеря возвращает навигацию.
- Короткие очереди 0.22 с / пауза 0.18 с сохранены; их глобальное сокращение по записи не обосновано.
- aim_contact: first_fire_ms измеряет время от первого выбранного детекта до отправки команды огня, frame_age_ms — возраст кадра. Это не задержка от первого появления противника на видео и не измерение регистрации выстрела игрой.

Проверка: 83 теста наведения, стрельбы, выбора класса цели и контакта прошли. Дополнительно проверяется навигационное управление камерой. Тесты геометрии подтверждают перенос координат, исключение ложной скорости от камеры, отсутствие повторной коррекции, запрет стрельбы по устаревшему кадру и ограничение удержания контакта.

Ограничения: Windows/CS2 здесь не запускались. Улучшение К/Д и визуальная естественность требуют игрового сравнения. Геометрическая компенсация зависит от корректного x360 и предполагает применение отправленных команд игрой. Полноценное удержание идентичности противника среди нескольких пересекающихся целей не добавлено. Оценка детектора по размеченному видео не выполнена; телеметрия помогает отделить его задержку от наведения.

Архив содержит только боевые исходники, идентификатор версии, тесты и эту документацию. Меню, вход в Steam, FarmPanel, профили карт и аккаунты не обновляются.
