# Свободное перемещение — visual-nav-dm-1

## Запуск

Распакуйте накопительное обновление в корень панели с заменой файлов. Закройте старые процессы перед обновлением.

Для встроенной маски: tools/navigation/StartDeathmatchNavigation.bat. Сеанс 10 минут, F8 включает/выключает движение, F10 завершает. Разрешение захвата 1280×720.

Для собственной подтверждённой маски: tools/navigation/NavigationStudio.bat → выберите маршрут проекта → включите «Свободное перемещение (внутри маски)» → начните тест. Маршрут нужен текущему формату сборки; в свободном режиме его цели не определяют последовательность движения. Используется маска сборки.

## Изменения

Цели автоматически выбираются внутри доступной области проходимости. Учитываются недавно выбранные места; путь проверяется планировщиком. При достижении цели выбирается следующая без секундного ожидания. При скачке координат или потере измерения прежний путь сбрасывается. Для продолжения нужны три отдельных согласованных измерения. Это восстановление позиции, а не отдельный детектор смерти по HUD.

Камера: скорость по умолчанию 300 градусов/сек вместо 100, повышенное ускорение и мягкое торможение. Настройка вручную: python scripts/nav_live.py --drive --roam --turn-rate 240. Допустимо 60–360. Калибровка чувствительности мыши остаётся прежней; реальное время зависит от неё и качества кадров. В симуляции с задержкой наблюдения 50 мс разворот 180 градусов достигает ошибки менее 2 градусов за 1,3 секунды.

## Границы этой версии

Свободный выбор целей работает только внутри подтверждённой маски и при доступной визуальной локализации. Встроенный профиль по-прежнему ограничен Mid Dust2: случайные спавны по всей карте ещё не поддержаны. Другие этажи, переходы, автоматическое построение атласа, самостоятельное изучение неизвестной территории и обход динамических препятствий не добавлены. При исчерпании существующего восстановления после застревания управление останавливается. Основной боевой цикл панели автоматически не переключается: используйте отдельный запуск выше.

Не проверено в CS2 на Windows в этом релизе. Следующий обязательный этап — расширение профиля и независимые записи со спавнами из разных областей. Для диагностики сохраняйте JSONL и summary сеанса. Видео на отключённом внешнем диске при разработке было недоступно.
