# Mirage и автоматический выбор карты

Движок: visual-nav-multimap-1. Единственный запуск фарма — FarmPanel.bat.
Farm.bat, если сохранён, вызывает ту же панель. Панель запускает общий worker
с аимом, автострельбой и навигацией. Выбирать профиль карты вручную не нужно.

## Автоматический выбор
CSGOBOT_NAV_PACK=auto: распознанная Dust2 выбирает dust2_visual_mvp и расширенную
проходимость Dust2; Mirage выбирает mirage_visual и профиль de_mirage.
Название читается из HUD/экрана найденного матча. Если названия нет и текущая
локализация потеряна, проверяется геометрия миникарты обеих карт: нужен
однозначный результат трёх проверок. До подтверждения карты движение отключено.
После смены карты сбрасываются маршрут, предыдущая позиция, история препятствий
и фильтр позы. Аим и навигация сохраняют общую очередь управления камерой.

В старом коде распознавание карты ошибочно зависело от включённого
макропатруля. Эта зависимость устранена; макропатруль не включается.

## Профиль Mirage
resources/nav/profiles/de_mirage: атлас, маска, описание, preview.png.
31 привязка получена напрямую по SIFT и независимым контурам радара;
ещё 3 — глобальным поиском контуров с просмотром наложения на кадр.
Для трёх последних автоматический контурный порог НЕ пройден; это явно
записано в manifest, а не представлено как автоматическая верификация.
Исходная запись: 2026-09-13 16-49-19.mp4, 1280×720, 205.67 сек.
Её SHA256 хранится в atlas.json. Контрольные точки Mid, A, B, CT, T,
T-side, T-long, Palace, Back hall и Market соединены в маске.
Цели выбираются свободно с учётом посещений, а не по записанному маршруту видео.

## Границы готовности
Это расширение существующего контроллера Dust2, а не доказательство
безошибочной навигации всей Mirage. Маска построена по радару и просмотренным
зонам. Это не 3D navmesh: вертикальная лестница, наложения этажей и прыжковые
переходы не подтверждены. Малые изолированные области могут оставаться.
Запись используется и для подготовки, и для проверки на других кадрах:
это НЕ независимый игровой тест. Отдельные участки теряют локализацию;
при такой потере ввод останавливается, слепого движения нет.
Windows, смена реальных матчей и полный набор случайных спавнов требуют
живой проверки. full_map_ready и live_validated остаются false.

## CMD: тренировка без панели
Не запускайте второй worker одновременно с сессией панели.
Из корня R.I.P.-Panel:

```bat
set "CSGOBOT_NAV=1"
set "CSGOBOT_NAV_READ_ONLY=0"
set "CSGOBOT_NAV_MODE=expanded_roam"
set "CSGOBOT_NAV_PACK=auto"
set "CSGOBOT_TARGET_MODE=ffa"
set "CSGOBOT_AUTO_ACTIVATE=0"
cd vendor\csgobot
venv\Scripts\python.exe -u run.py
```
CapsLock — активность, Ctrl+Q — выход. Если карта ещё не определилась,
на время покажите игровую таблицу счёта с названием карты и закройте её.
В логе ищите `map: confirmed mirage` и `nav: auto pack mirage_visual`.
Для Dust2 — `dust2` и `dust2_visual_mvp` соответственно.

## Воспроизведение проверок
scripts/nav_replay_check.py теперь принимает --map de_mirage (или de_dust2).
scripts/nav_live.py принимает --map de_mirage --roam --drive для отдельной
диагностики навигации. Продуктовый запуск по-прежнему через панель.
scripts/build_mirage_walkable.py пересобирает маску из радара и floor_regions.json;
scripts/rebuild_mirage_atlas.py --video <исходное видео> --out <новый каталог>
воспроизводит кропы по записанным преобразованиям; произвольное другое видео
отклоняется по отпечатку. Эти инструменты не отправляют ввод в игру.
