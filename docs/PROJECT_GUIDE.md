# Единый запуск и структура проекта

## Запуск теста
1. Рабочий каталог — farm-panel-prototype (на Windows ваш R.I.P.-Panel).
2. Запустите FarmPanel.bat. Farm.bat открывает ту же панель.
3. Выберите аккаунт и запускайте обычную сессию через панель.
   Навигация и автострельба запускаются одним дочерним процессом.
4. Для ручного теста уже открытого матча worker — vendor/csgobot/run.py;
   это не панель. Не запускайте его параллельно с фармом панели.
5. CapsLock переключает активность worker, Ctrl+Q завершает его.
   Остановка всей сессии — через панель.

Панель включает expanded_roam, NAV=1, auto pack и автоматическую активацию.
Явный CSGOBOT_NAV_READ_ONLY=1 сохраняется для диагностики без движения.
1280×720 и настроенный захват нужны по-прежнему. Потеря позиции/фокуса
останавливает ввод. Shift для движения не используется.

Родительский FSM_PANEL с Panel.exe — исходная отдельная дистрибуция.
Она не изменена. Не смешивайте её файлы с этим проектом.
Окружения .venv, vendor/csgobot/venv, модели *.pt, датасеты, looter,
Steam Guard и пользовательские настройки не перемещены и не удалены.

## Навигация
Рабочая цепочка: run.py → main.py → nav/farm_runtime.py →
VisualNavController + VisualPerception/VisualLocalizer + RoamingPlanner.
Старый макропатруль выключен по умолчанию; при потере позиции нет
переключения на слепое движение. Старые модули оставлены там, где есть
импорты/тесты и совместимость; их наличие не означает запуск старой навигации.
Navigation Studio открывается из панели и служит инструментом калибровки.

Расширенный профиль всё ещё экспериментальный: этажи и отдельные переходы
не полностью описаны. Упорядочивание проекта не означает устранения всех
застреваний и не заменяет Windows-тест.

## Обновление Windows
Закройте панель и worker. Распакуйте обновление поверх существующего проекта.
Запустите tools/maintenance/OrganizeLegacyLaunchers.ps1 через PowerShell:
`powershell -ExecutionPolicy Bypass -File tools\maintenance\OrganizeLegacyLaunchers.ps1`
Скрипт переносит только известные старые корневые BAT в резервную папку,
если соответствующий новый BAT уже присутствует. Данные не затрагиваются.
Далее запускайте FarmPanel.bat. Старый dist/FarmPanel/FarmPanel.exe
можно использовать только после новой сборки build/build_windows.ps1.
Новую Windows-сборку необходимо отдельно проверить; окружение worker,
веса и Node-зависимости устанавливаются на целевой машине.

## Проверка версии и логи
В логе worker должны быть visual-nav-dm-3 и mode=expanded_roam.
Логи сессии: data/logs/csgobot_<session>.stderr.txt.
Полный код обновления находится локально; автоматического git push нет.

## Запуск без консоли
FarmPanel.bat запускает launch_panel.pyw через pythonw.exe: окно терминала
не остаётся открытым. Farm.bat использует этот же запуск.
BAT при двойном щелчке может кратко показать системное окно командной строки.
При корректной ассоциации Python в Windows можно запускать launch_panel.pyw
напрямую, чтобы избежать и этого краткого появления.
Ошибки запуска пишутся в data/logs/panel-startup.log; при сбое появляется
диалог с путём к журналу. При FARM_PANEL_DATA_DIR журнал находится в его logs.
