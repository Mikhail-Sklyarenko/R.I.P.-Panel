# Nuke: исправление блокировки запуска навигации

В предоставленном журнале профиль Nuke успешно загружен, нижний уровень и координаты измеряются с уверенностью около 0.8. Однако все тики движения имеют external_pause, а задачи не находят доступной цели.

Причина: контроллер выбирал маску измеренного этажа только после проверки паузы. Без задачи Wingman ставил навигацию на паузу, а задача нижнего этажа пыталась строиться по начальной верхней маске. Теперь свежие измерения этажа обрабатываются и в паузе, без выдачи команд движения. Планировщик получает правильную маску и может создать задачу.

Также исправлено сравнение времени: GSI может поступить после захвата кадра. При обработке состояния теперь используется текущее время приёмника; возраст самого наблюдения не изменяется. Просроченные данные по-прежнему блокируют действия.

Закройте процесс бота и панель. Распакуйте wingman-nuke-2.zip в корень R.I.P.-Panel с заменой файлов. Запустите тем же способом. В журнале должны быть wingman_nuke_fix_2 и profile_version=wingman-nuke-2 после определения Nuke.

Ваша команда CSGOBOT_NAV_PACK=inferno_visual не была причиной: журнал подтверждает автоматическое переключение на Nuke. Менять её для этого исправления не требуется.

Проверено воспроизведение порядка реального цикла: отсутствие задачи → пауза → измеренный нижний этаж → планирование → команды движения. Это регрессионный тест с моделью ввода, а не подтверждение нового живого прогона Windows.
