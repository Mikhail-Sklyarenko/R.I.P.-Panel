# Напарники / Inferno — игровой тест 1

Добавлен запуск одного текущего аккаунта из существующей FarmPanel. Это сборка для проверки игрового цикла, а не подтверждённый автономный фарм: полный матч на Windows после этих изменений ещё не проверен. Создание лобби и автоматический поиск Напарников не реализованы. Обычная очередь с выбранным режимом «Напарники — в разработке» по-прежнему останавливается до запуска аккаунта и не подменяет режим Deathmatch.

## Что подключено

- Данные собственного игрока через локальный GSI: стадия и номер раунда, сторона, здоровье, деньги, оружие и состояние бомбы. Чужой игрок при наблюдении не разрешает управление.
- Навигация и существующий боевой модуль работают в LIVE; фильтр противников соответствует текущей стороне. После смерти, окончания раунда, потери фокуса или устаревания данных ввод прекращается.
- Закупка во время FREEZE: броня, доступный основной ствол, набор обезвреживания за CT при наличии денег. Каждая покупка подтверждается изменением инвентаря и баланса; неподтверждённая команда не повторяется. Гранаты, полный каталог экипировки, ремонт брони и закупка «под ноль» пока не реализованы.
- За T с C4: движение к тестовой точке A, выбор C4 и удержание установки. За CT при установленной бомбе: обход тестовых точек A и попытки обезвреживания; распознанная шкала позволяет продолжить удержание E. Это поиск по области, не точная локализация бомбы. Гарантия нахождения любой установки отсутствует; возврат к выпавшей C4 ещё не реализован.
- Отдельная ограниченная маска A-стороны Inferno. Маршруты от двух измеренных стартовых точек к цели проверены вне игры. Маска получена ограничением существующего DM-профиля, а не полной разметкой всех границ Напарников; она не считается подтверждённым покрытием всего режима.
- HUD-блокировки закупки, конца раунда, смены сторон, обезвреживания и экрана победы. Деньги берутся из GSI, а не из ненадёжного OCR.

## Как запустить на Windows

1. Остановить фарм и закрыть панель. Распаковать обновление в корень существующей установки, сохранив структуру каталогов. Данные аккаунтов и веса модели в обновление не включены.
2. Открыть `FarmPanel.bat`. В настройках проверить путь к `cs2.exe` и нажать **«Тест Напарников — текущий матч»**. Первый запуск устанавливает отдельный файл GSI и сообщает, что необходимо один раз перезапустить CS2. На этом шаге бот ещё не запускается.
3. Перезапустить CS2. Открыть тестовый матч **Inferno / Напарники** с ботами на текущем аккаунте. Требуются русский HUD, изображение 1280×720 с прежним масштабом HUD, включённая консоль разработчика и работающая OBS Virtual Camera. Поиск игры и вход в аккаунт эта кнопка не выполняет.
4. Повторно нажать **«Тест Напарников — текущий матч»**, затем переключиться в игру. Боевой процесс активируется автоматически, когда окно игры активно. Он ожидает свежие данные собственного живого игрока; во время разминки управление не начинается.
5. Первая подготовка задаёт `cl_radar_rotate 0`, привязывает `5` к `slot5`, `E` к `+use`. Эти настройки меняются в игре. Поворот радара отключается, поскольку имеющийся профиль локализации рассчитан на север сверху. Консоль должна открываться стандартной клавишей; выполнение команд пока не подтверждается отдельным распознавателем консоли.
6. Для остановки нажать **«Остановить тест Напарников»** в панели. Обычная кнопка остановки фарма также останавливает тест; CapsLock в боевом процессе приостанавливает/возобновляет управление. Одновременный запуск очереди DM и теста блокируется. Тест не отмечает аккаунт как отфармленный.

После установки GSI следующие запуски не требуют повторного перезапуска CS2, пока файл конфигурации не изменился. Файл канала: `game/csgo/cfg/gamestate_integration_farm_panel_wingman.cfg`. Локальные параметры: `data/wingman_receiver.json` — не передавать этот файл другим пользователям. Приёмник слушает только 127.0.0.1:4019; доступ к серверу защищён локальным токеном. Занятый порт приводит к явной ошибке запуска.

## Диагностика и критерии проверки

Панель показывает путь к `data/logs/csgobot_wingman-<id>.stderr.txt` (каталог может отличаться при настройке пути данных). Ищите строки `CS2Bot.wingman`: `gsi mode=... map=... phase=... supported=...`, `state=...`, `buy_plan`, `buy_sent`, `interaction`. При `waiting_for_fresh_game_state` проверить перезапуск CS2 после установки GSI; при `supported=False` проверить карту и режим. В текущем адаптере ожидается GSI mode `scrimcomp2v2`, map `de_inferno`; фактический пакет CS2 на целевом ПК ещё не получен. Неизвестный формат не включает движение вслепую.

Проверка должна включать: закупку без повторов; отсутствие стрельбы по союзнику за обе стороны; движение со стартов T и CT; установку в живом раунде; обезвреживание; смерть и наблюдение; следующий раунд; смену сторон; конец матча; остановку при выключении виртуальной камеры и при переключении окна. Для разбора нужен журнал и запись одного полного тестового матча. Успешные модульные проверки не заменяют эту проверку.

HUD проверен на отдельных временных отметках записи `2026-09-20 20-01-41.mp4`, но не на независимом матче. Вращавшийся радар этой записи не даёт полного подтверждения маршрутов с новым фиксированным радаром. Экран поражения в матче отдельно не откалиброван; конец матча дополнительно определяется по GSI `gameover`. Победа, отсутствие застреваний и успешность каждого обезвреживания не заявляются.
