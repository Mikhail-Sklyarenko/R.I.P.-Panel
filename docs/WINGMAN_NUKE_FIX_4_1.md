# Nuke Wingman: исправление запуска 4.1

Причина сбоя в журнале 2026-09-24 20:03–20:04: после получения de_nuke по GSI проверка nav/preflight.py требовала ровно два слоя upper/lower. Обновление 4 добавило третий слой ramp. Проверка отвергала профиль с Invalid navigation layer configuration, после чего DetectionProcess завершался.

Исправлена схема проверки: Nuke требует upper/lower/ramp с точными идентификаторами профилей; Vertigo сохраняет upper/lower. Проверяются принадлежность конфигурации карте, наличие масок и атласов. Проверка безопасности не отключена. Добавлены тесты реального preflight Nuke и некорректных/неполных профилей.

Закройте панель и бота, распакуйте весь wingman-nuke-4.1.zip в корень R.I.P.-Panel с заменой файлов. Команды запуска остаются прежними. Начальный CSGOBOT_NAV_PACK=inferno_visual допустим: при получении GSI карта автоматически меняется на Nuke.

Этот пакет устраняет подтверждённый отказ проверки запуска. Ограничения навигации и отсутствие живой проверки CS2 из WINGMAN_NUKE_FIX_4.md сохраняются.
